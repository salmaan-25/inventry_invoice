## 1. Requirements Implemented

All requirements from the Phase 8 spec (Sections 0–6 and Phase 8) have been implemented:

### Data Model
- **`expenses.ExpenseCategory`**: `name` (unique, max_length=100). Seeded through Django admin: Rent, Electricity, Transport, Salary, Repairs, Other.
- **`expenses.Expense`**: 
  - `date` (DateField, required)
  - `category` (FK to ExpenseCategory, on_delete=PROTECT)
  - `description` (TextField, blank=True, default="")
  - `amount` (DecimalField, max_digits=14, decimal_places=2, >0)
  - `payment_method` (CharField, max_length=20, optional: CASH, UPI, BANK_TRANSFER, CHEQUE)
  - `paid_to` (CharField, max_length=255, optional)
  - `notes` (TextField, blank=True, default="") *[added]*
  - `recorded_by` (FK to AUTH_USER_MODEL, on_delete=PROTECT)
  - `created_at`, `updated_at` (auto timestamps)

### Endpoints
| Method | Path | Filters | Purpose |
|---|---|---|---|
| GET | `/api/expense-categories/` | — | Category list (any auth) |
| GET | `/api/expenses/` | `?search=`, `?category=`, `?from=`, `?to=` | List with pagination, total_amount for all filtered records |
| POST | `/api/expenses/` | — | Create expense (admin/staff) |
| GET | `/api/expenses/{id}/` | — | Detail (admin/staff) |
| PATCH | `/api/expenses/{id}/` | — | Partial update (admin/staff) |
| GET | `/api/expenses/export/` | `?from=` & `?to=` | Excel (.xlsx) export (admin/staff only) |

### D14-style immutability
- No delete endpoint for expenses in V1 (PROTECT on category/recorded_by FKs)

### D15 (expense export columns)
- Default columns: Date, Category, Description, Payment method, Paid to, Notes, Amount, Recorded by

### D16 (shared export helper)
- `apps/common/exports.py` reused by both Phase 8 and Phase 9

- **No delete endpoint** for expenses in V1 (D14 default applied analogously — PROTECT on FKs prevents accidental deletion)

- **OpenAPI generation** has pre-existing "unable to guess serializer" errors for APIView-based endpoints (known issue, out of scope)

- **PostgreSQL** is the test database; `.env` is configured
